# 代码审核检查清单

## ECS 架构合规性

### Components 组件检查
- [ ] 仅包含数据结构（Interface/Type 定义）
- [ ] 无任何函数或方法实现
- [ ] 字段有清晰的 JSDoc 注释说明含义和范围
- [ ] 位于 `src/engine/components/` 目录

### Systems 系统检查
- [ ] 函数为纯函数，无副作用（除修改 World 状态）
- [ ] 接收 World 和 deltaTimeMs 作为参数
- [ ] 使用 view 函数查询实体，不直接访问
- [ ] 有完整的 JSDoc 注释：处理组件、逻辑目的、副作用
- [ ] 位于 `src/engine/systems/` 目录

### Blueprints 蓝图检查
- [ ] 仅定义实体初始配置
- [ ] 不包含运行时逻辑或状态
- [ ] 位于 `src/engine/blueprints/` 目录

### Events 事件系统检查
- [ ] 事件类型在 `src/engine/events.ts` 定义
- [ ] 所有事件**本帧生成和消费**
- [ ] 无跨帧事件传递
- [ ] 事件队列每帧清空

### 目录隔离检查
- [ ] 新代码位于 `src/engine/`
- [ ] 未在 `game/` 废弃区修改代码
